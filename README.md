# [NAME] 📚

A study monitor that keeps you focused, tracks your progress, and tells you what to study next.

## Roadmap

### Phase 1: Core Focus Monitor (MVP)
The basics: know what you're doing and notice when you drift.

- [ ] Monitor the active browser tab **or** the entire screen
- [ ] Allowlist manager for approved apps and websites
- [ ] Detect off-task activity after a configurable threshold (e.g., 5–10 seconds)
- [ ] **Gentle mode:** show a warning or reminder to get back to studying

### Phase 2: Timers & Session Tracking
- [ ] Regular timer and Pomodoro timer (customizable work/break intervals)
- [ ] Log study sessions (start time, duration)
- [ ] Track productivity: how long you studied before switching to a distraction
- [ ] Pick a class before starting a session

### Phase 3: Stats & Motivation
- [ ] Rank your top distracting websites/apps
- [ ] Personal Best system: longest focused study streak
- [ ] Per-class breakdown: see which classes you've studied most and which need more attention
- [ ] Deadline dashboard: upcoming midterms/finals sorted by date, with suggestions for what to study most urgently

### Phase 4: Enforcement & Personality
- [ ] **Strict mode:** forcibly return you to a prior study window or the monitor itself
- [ ] Customizable characters that change the tone of warnings (e.g., *kind*, *base*, *stern*)

### Phase 5: Multi-Device & Advanced Detection
- [ ] Webcam monitoring to detect phone use
- [ ] Laptop + iPad integration with combined productivity tracking across devices
